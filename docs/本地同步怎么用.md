# 本地同步怎么用（git-sync v2.10+）

## 第零节：我该用哪个文件夹？

本机可能同时存在多份克隆（不同会话各有自己的工作目录），先问
`where` 再动手，**永远不要猜**：

```powershell
cd <任意一份克隆或 skills\git-sync\scripts 所在处>
.\where.cmd                          # 列出本机找到的所有克隆 + 各自分支
.\where.cmd -Want arena/01a0b237-browserskill   # 直接标出本会话该用的文件夹
.\where.cmd -Want 01a09d79           # 只给会话 id / 分支片段也行
```

输出里带 `[USE]` 标记、末行 `use THIS folder:` 的就是要用的目录。

本机（LAPTOP-R77M5D6M）实际存在的两份 BrowserSkill 克隆：

| 文件夹 | 分支 | 归属 | 用途 |
|---|---|---|---|
| `E:\0github\git-sync\BrowserSkill-01a0b237` | `arena/01a0b237-browserskill` | **桥接值守**（计划任务 git-sync-watch-BrowserSkill-01a0b237） | 沙箱↔本机的任务通道，验收判定从这里推回 |
| `E:\0github\BrowserSkill-01a0b352` | `arena/01a0b352-browserskill` | arena 的 agent（会话 01a0a821 的克隆） | arena agent 自己的仓库，别手动改 |

扫描范围：脚本所在克隆的全部上级 + `E:\0github`、`E:\0github\git-sync`、
`E:\0zhongqi` 的一级子目录。找不到时把新克隆放进这些位置即可被识别。

## 第一节：日常三件套

```powershell
.\sync.ps1        # 拉取远端最新（沙箱推上来的任务/产物）
.\download.ps1 -Set final        # 把 deliverable 等产物复制到 <repo>_out\
.\where.cmd -Want <分支>         # 忘了该用哪份克隆时先跑这个
```

`download.ps1` 跑完现在会打印**来源清单**：来源仓库 / 分支 / 提交 /
复制到了哪个目录 —— 拿到文件就能立刻看清是从哪份、哪个分支来的。

## 第二节：值守（watcher）

- 状态：`.\watch.ps1 -Status`（heartbeat 应在几分钟内）
- 被别的克隆抢焦点（单值守规则）：`.\watch.ps1 -RestoreParked` 恢复
- 彻底重装：`.\watch.ps1 -Unregister` 然后 `.\watch.ps1 -Register`

## 第三节：验收与收尾（沙箱侧视角）

沙箱用 `agent-wait.sh --request ...` 派活；本机值守跑 `code/agent_task.ps1`
并把 passed/failed 推回分支；沙箱 `agent-check.sh --accept ...` 收尾。
判据文件在 `results/status/check_rN_*.txt`，证据在 `results/jobs/`。
